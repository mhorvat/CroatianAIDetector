# CroatianAIDetector
This repository contains the complete codebase (including the application written in Python, LLM prompts, human-written academic texts, generated academic text documents and the utilized database) created for the research presented in the scientific paper **"Detecting AI-Generated Text in the Croatian Language Through Syntactic, Semantic, and Stylistic Analysis"** published at the 7th International Conference on Smart Systems and Technologies (SST 2026), held in Osijek, Croatia, 28 - 30 October 2026.

Conference website: https://sst-conference.org/

**The developed application is available only for research and non-commercial use.**

For more information and instructions on how to use the application, contact the application's creator **Ariana Dobrostal** (ariana.dobrostal@proton.me).

Please correctly cite the paper as:

A. Dobrostal and M. Horvat, "Detecting AI-Generated Text in Croatian Using Syntactic, Semantic, and Stylistic Features," in *Proc. 7th Int. Conf. Smart Syst. Technol. (SST) 2026*, Osijek, Croatia, Oct. 30, 2026.
